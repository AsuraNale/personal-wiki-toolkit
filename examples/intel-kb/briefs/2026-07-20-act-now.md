## 1. Patch first: exploited in the wild

**SharePoint Server — CVE-2026-58644 (RCE, zero-day)**
Added to CISA's KEV catalog while already under attack; federal remediation deadline
was **2026-07-19** — i.e. it is already past due for agencies, and public exploitation
predates the deadline. On-prem SharePoint is the exposure; check before assuming
you only run the hosted product.
→ `https://thehackernews.com/2026/07/cisa-adds-exploited-sharepoint-rce-zero.html`

**SonicWall SMA 1000 — two zero-days, one CVSS 10.0**
Vendor-confirmed active exploitation. One is an SSRF at **CVSS 10.0 (CVE-2026-15409)**;
the second enables arbitrary command execution. SMA 1000 is a remote-access appliance —
i.e. internet-facing by design, which makes this the highest-priority perimeter item
in this brief.
→ `https://thehackernews.com/2026/07/two-sonicwall-sma-1000-zero-days.html`

**ServiceNow AI Platform — CVE-2026-6875 (RCE)**
Moved from "critical" to "actively exploited" per Defused telemetry. Worth flagging
separately because ServiceNow tends to sit deep in change-management workflows —
compromise there reaches further than the CVE description suggests.
→ `https://www.bleepingcomputer.com/news/security/critical-servicenow-code-execution-flaw-now-exploited-in-attacks/`

## 2. Schedule this cycle

**Microsoft — 622 CVEs, two already exploited**
Largest Patch Tuesday on record. The volume is the story: a 622-CVE month cannot be
triaged item-by-item, so drive off the two exploited zero-days first and let the rest
follow normal ring deployment.
→ `https://thehackernews.com/2026/07/microsoft-patches-record-622-flaws.html`

**nginx — CVE-2026-42533 (unauthenticated heap overflow)**
Reachable with a crafted HTTP request against the worker process; may allow RCE.
Fixed in **1.30.4 / 1.31.3 / NGINX Plus 37.0.3.1**. Unauthenticated + internet-facing +
a fixed version already published = no reason to defer this one.
→ `https://thehackernews.com/2026/07/critical-nginx-vulnerability-can-crash.html`
